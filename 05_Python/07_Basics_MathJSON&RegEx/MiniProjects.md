Project checklist

- [x] 1. Reusable Calculator <br>
`Easy - Functions`<br>
Create add, subtract, multiply, and divide functions. Return results instead of printing inside every function.

- [ ] 2. Array Statistics<br>
`Easy - Arrays and functions<br>
Store numbers in an array. Write functions to calculate the sum, average, maximum, and minimum.

- [ ] 3. Number Generator<br>
`Easy–Medium - Iterators and generators`<br>
Write a generator that produces even numbers from 2 up to a user-specified limit.

- [ ] 4. Personal Utility Module<br>
`Medium - Modules`<br>
Create a utilities.py module containing functions for calculating percentages and converting temperatures. Import them into main.py.

- [ ] 5. Age and Days Calculator<br>
`Easy–Medium - Dates`<br>
Ask for a birth date in YYYY-MM-DD format. Parse it and calculate the person's age in years. Handle invalid dates.

[ ] 6. Expense Calculator<br>
`Easy–Medium - Math and functions`<br>
Store expenses in a list. Calculate the total, average, largest expense, and smallest expense.

- [ ] 7. Student JSON Manager<br>
`Medium - JSON and modules`<br>
Store student records in a JSON file. Load the file, add a student, and save the updated data.

- [ ] 8. Text Analyzer<br>
`Medium - RegEx, functions, iterators`<br>
Read a text string and extract all numbers, email-like addresses, and dates in DD-MM-YYYY format. Count the matches.

Final revision checklist
Before moving on, make sure you can explain these concepts without looking at your notes:
- [x] Functions: parameters, arguments, return, default values, *args, **kwargs.
- [x] Arrays: Python lists, the built-in array module, and NumPy arrays.
- [x] Iterators: iterable vs. iterator, iter(), next(), yield.
- [x] Modules: import, custom modules, and __name__ == "__main__".
- [x] Dates: date, datetime, strftime(), strptime(), timedelta.
- [x] Math: math.sqrt(), ceil(), floor(), factorial, and precision.
- [x] JSON: dumps(), loads(), dump(), load().
- [x] RegEx: search(), findall(), fullmatch(), sub(), and capturing groups.

One small correction to remember from your earlier practice: to check a variable's type, use type(status), not status.type().
