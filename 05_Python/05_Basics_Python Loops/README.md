# Part C — Python Loops

Loops let you execute code repeatedly without writing the same statements again and again.

## Topic 17 — Python While Loops

A `while` loop repeats while its condition remains true.

### 17.1 Basic while loop

```
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output:
```
1
2
3
4
5
```
